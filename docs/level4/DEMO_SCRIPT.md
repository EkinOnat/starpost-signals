# Level 4 demo script

Target length: 3–5 minutes.

1. State the cross-border microgrant problem and Testnet limitation.
2. Live-record the existing Signals result and open the proof view on mobile width.
3. Show a prepared draft, then live-sign role acceptance or project creation.
4. Show a real funded project and live-sign a small contribution.
5. Upload non-personal evidence, display stored/hash states, then anchor it.
6. Use prepared accounts/state to show reviewer threshold and contributor approval or dispute.
7. Live-sign one decision and keep its confirmed transaction and Explorer page visible.
8. Show the exact Escrow payout receipt or refund from prepared Testnet state.
9. Show the public raw audit trail, direct contract state, `/ready`, analytics/monitoring dashboards, responsive layouts, test output, and architecture.
10. Show verified ten-user CSV results and authentic feedback summary, then state Mainnet/audit/anchor limitations.

Prepared Testnet state is acceptable for long windows and multi-account thresholds, but every shown transaction, address, hash, and dashboard must be real. Do not stage a fiat cash-out or call Starpost an anchor.
