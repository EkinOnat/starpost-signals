## Required visible proof

- Live production URL and Testnet warning.
- One uncut wallet-authorized transaction lifecycle through RPC success.
- Transaction hash, actor wallet, approved contract, and Stellar Expert result.
- Guided onboarding, mobile/responsive proof, and configuration-safe Form behavior.
- Exactly 50 verified Level 5 users only after the public verifier reports 50 passes.
- Aggregate funnel and transaction activity screenshots with capture date and release.
- Sanitized workbook and public verification JSON without names or emails.
- Two authentic feedback-driven changes and their direct GitHub commit links.
- Architecture, growth strategy, retention result, security limitations, and roadmap.

## Failure-safe recording rules

- Never edit video to convert a failed or pending transaction into apparent success.
- Never reuse the ten Level 4 users in the Level 5 counter.
- Never show a raw Google Sheet, raw Excel export, private email, or browser autofill suggestion.
- Never invent a rating, testimonial, retention percentage, analytics count, or transaction.
- If an external dependency is unavailable, say so on-screen, show the graceful failure state, and record the successful flow in a later continuous take.
