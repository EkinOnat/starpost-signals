# Level 5 submission checklist

## Development release

- [ ] Guided onboarding for four personas
- [ ] Wallet, Testnet, funding, action, confirmation, and feedback steps
- [ ] Aggregate onboarding funnel metrics
- [ ] Public indexer/evidence service with `/health`, `/ready`, and `/api/v1/metrics`
- [ ] Responsive, accessible, and failure-state QA
- [ ] Google Form and private raw response workbook
- [ ] Sanitized public workbook template
- [ ] Level 5 cohort verifier and negative-case tests

## Authentic user campaign

- [ ] Wave 1: 10 qualified new users
- [ ] First feedback-driven improvement and commit link
- [ ] Wave 2: 20 qualified new users
- [ ] Second feedback-driven improvement and commit link
- [ ] Wave 3: 20 qualified new users
- [ ] Exactly 50 verified new wallets, people, form records, and transactions
- [ ] At least ten deeper lifecycle actions beyond the Signals vote
- [ ] Seven-day repeat-activity result reported honestly

## Presentation and submission

- [ ] Public live application
- [ ] Analytics and transaction screenshots
- [ ] Sanitized `.xlsx` linked from README
- [ ] Restricted raw workbook link available to judges
- [ ] Professional 12-slide `.pptx`, PDF, and public view link
- [ ] Narrated 6–8 minute walkthrough link
- [ ] README feedback iteration table with direct Git commit links
- [ ] 20+ meaningful Level 5 commits
- [ ] Final public repository submitted before the deadline

Unchecked cohort, feedback, recording, and external-account items must remain unchecked until authentic evidence exists.
